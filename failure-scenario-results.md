# บันทึกผลการทดสอบ Failure Scenario

| สถานการณ์                          | วิธีจำลอง                                                | ผลลัพธ์ที่คาดหวัง                              | ผลลัพธ์จริง                                                         | ผ่าน/ไม่ผ่าน |
| :--------------------------------- | :------------------------------------------------------- | :--------------------------------------------- | :------------------------------------------------------------------ | :----------: |
| Network error (โดเมนไม่มีอยู่จริง) | เปลี่ยน URL เป็นโดเมนปลอม                                | Retry 2 ครั้ง แล้ว fallback พร้อมข้อความชัดเจน | Retry 2 ครั้งตามระยะเวลา Jitter แล้วคืน source: fallback            |     ผ่าน     |
| Timeout                            | ตั้ง timeoutMs = 1                                       | เกิด ECONNABORTED แล้วคืน fallback             | เกิด ECONNABORTED (timeout of 1ms exceeded) ตามคาด แล้วคืน fallback |     ผ่าน     |
| External API คืน 500               | เปลี่ยน URL เป็น Mock Server 500 (http://localhost:4000) | Retry เนื่องจากเป็น 5xx แล้วคืน fallback       | Retry 2 ครั้งตามที่คาดจาก status 500 แล้วคืน fallback               |     ผ่าน     |
